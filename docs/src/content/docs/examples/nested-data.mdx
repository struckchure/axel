# Nested data in one query

Fetch a row together with its related rows in a single query. A nested
[shape](/aql/select/nested) compiles to a `json_agg` lateral subquery, so
PostgreSQL returns the parent and its children as one JSON structure — no second
round trip, no N+1.

```aql
multi select User {
  id,
  email,
  articles := (multi select Article { id, title } filter .owner = User.id)
};
```

compiles to:

```sql
SELECT
  u.id AS id,
  u.email AS email,
  (SELECT COALESCE(json_agg(row_to_json(a_articles_sub)), '[]')
     FROM (SELECT a.id AS id, a.title AS title
             FROM "article" a WHERE a.owner = u.id) a_articles_sub) AS articles
FROM "user" u;
```

- The inner `multi select` yields a JSON **array** (`[]` when empty); drop `multi`
  for a single related object instead.
- `User.id` refers to the outer row — that's how the subquery correlates children
  to their parent.
